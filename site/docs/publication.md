# Publication model

Own-tag activation; exact direct source; highest-semver dependent cascades. Status shows the highest version.

## Latest release, Available and In-build

Status shows the highest semantic version, including pending or failed work. Available and Published belong to that highest entry and never borrow an older success. An older direct build still builds/signs/publishes but does not replace the highest display. In-build links point only to real source jobs. Authored guides refresh independently.

Latest release is the source version only. Each Available/In-build cell keeps its row’s package revision. A green current indicator compares the available package with that row’s newest captured revision of the highest version. Matching cascade captures may share a number across rows, but differences in history or prerequisite release identities can still diverge them. Sharing records reservation-time release provenance, not equal package bytes or the inputs of a later pinned rebuild. Direct captures stay fresh.
